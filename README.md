# CSAW 2025 — AI Hardware Attack Challenge

NYU CSAW AI Hardware Attack Challenge 2025 entry. Every hardware Trojan here was
generated by one autonomous, self-verifying AI pipeline — no RTL or testbench
was hand-written by a human.

- **`csaw_aha/`** — the pipeline: a reusable agentic Trojan-insertion framework
  that composes six AI technique models (task decomposition, hybrid retrieval,
  pipeline RAG, parallelization, answer verification, caching) into one loop
  whose acceptance gate is a *real* EDA toolchain (Icarus Verilog + Yosys).
- **`csaw_submissions/`** — the deliverables for all three challenges, each in
  the required `README / rtl / tb / synth / ai` layout.

Start with [`csaw_submissions/README.md`](csaw_submissions/README.md) for the
per-challenge results and [`csaw_submissions/PIPELINE.md`](csaw_submissions/PIPELINE.md)
for the pipeline architecture.

## Challenges

| Challenge | Trojan | Verified |
|---|---|---|
| C1 easy (AES) | key byte/encryption via reserved register | functionality + full-key recovery + synth |
| C1 medium (AES) | magic-key previous-plaintext replay, split across 2 modules | functionality + exploit + synth |
| C1 hard (AES netlist) | `key[7:0]` via ciphertext LSB, 1 bit/encryption | normal vector + key recovery + synth |
| C2 easy (wbuart32) | Wishbone DoS with arm/disarm sequences | exploit + synth |
| C2 medium (wbuart32) | one-shot Setup-register spoof (`0xdeadbeef`) | exploit + synth |
| C2 hard (wbuart32) | covert channel over Wishbone ACK timing, <5% area | exploit (byte recovered) + synth |
| Final (OpenTitan) | AES key exfiltration via reserved CSR alias | design + patch + DV exploit sequence |

## Generator

Anthropic Claude `claude-opus-4-8`, driven through the Claude Code agentic
harness. Complete interaction logs are in each challenge's `ai/` directory (the
competition disqualifies submissions without them).

## Running

Tools: [OSS-CAD Suite](https://github.com/YosysHQ/oss-cad-suite-build) (Icarus
Verilog + Yosys), or the competition Docker. Per-challenge commands are in each
`README.md`. For example:

```bash
cd csaw_submissions/challenge_1/01_easy
iverilog -g2012 -o x.out -s tb_aes_trojan rtl/*.v tb/tb_aes_trojan.v && vvp x.out
yosys -q synth/synth_trojan.ys
```

### The pipeline (`csaw_aha`)

The pipeline framework depends on the six *Prebuilt AI Technique* models
(the `pipeline_core` package and the six `*_model/` packages). Point it at a
checkout of that repository via an environment variable, then run:

```bash
export PREBUILT_MODELS_ROOT=/path/to/Prebuilt-AI-Technique-Models
python -m csaw_aha list
python -m csaw_aha plan c1_easy
python -m csaw_aha verify c1_easy --submissions csaw_submissions \
       --source csaw_submissions/_challenge_source --synth
```

`csaw_submissions/_challenge_source/` holds the unmodified golden IPs, used for
diffing and for the original testbenches.
